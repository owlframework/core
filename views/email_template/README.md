# Owl Core: Email Template Architecture

Welcome to the  email template directory for **Owl Core**. This folder houses clean, modular HTML presentation files (`.temp.php`) utilized by the core mailer engine to dispatch system notifications, password resets, verification codes, and alerts to users.
